CoinMonitor 隐私政策

CoinMonitor 是由 baiyanwu 维护的开源应用，无需注册账号，没有自建用户数据服务器。

1. 本地保存

自选、设置和历史保存在设备上。助记词、私钥和 API 凭证加密保存；签名在本地完成，不自动上传助记词或私钥。

2. 第三方服务

第三方行情、地址查询、RPC、AI 和 DApp 服务可能收到公开地址、主页标识、查询、认证信息及 IP，按各自政策保留数据。打开面板才读取剪贴板；AI 接收提问，DApp 可使用 Cookie。确认后的签名或交易交给对应服务。

3. 不追踪、不出售

没有广告或行为分析 SDK，不出售用户数据，不自动上传诊断日志。

4. 保留与删除

本地数据保留至您删除，可清除应用存储或卸载。部分数据可参与系统备份，钱包保险库已排除。备份由系统管理，第三方数据和区块链记录不随本地删除消失。

5. 联系

通过 GitHub Issues 联系。内容公开，请勿提交私钥或凭证。本页由 GitHub Pages 托管，可能记录访问 IP。
