# Changelog

## 未发布

## v1.0.10 (2026-09-07)

- 统一首页与两种悬浮窗的微小币价格式：小数部分连续前导 0 达到 3 个时使用下标计数压缩，例如 `0.0001234` 显示为 `0.0₃1234`
- 搜索页将真正退出页面的返回按钮固定在左上角，并把输入框右侧“取消”改为提交查询的“确认”
- 首页币对标题支持打开对应外部行情页：交易所映射到 Binance / OKX 行情，链上优先打开当前固定池的 DexScreener 页面
- 链上观察项按当前池显示 `目标币 / 另一侧币种`；新增、切池和报价刷新会同步交易对，旧观察项无需删除重加即可在下一次有效刷新后补齐

## v1.0.9 (2026-09-04)

- 悬浮窗新增“排列型 / 跑马灯型”选择：排列型保持原有外观和左右吸附行为，跑马灯型使用无描边的全屏宽单行细条，从右向左无缝循环显示币种图标和最新价
- 两种悬浮窗的窗口、渲染状态、触摸与动画实现拆分到独立代码空间；切换类型时先移除旧窗口，保证任意时刻只显示一种悬浮窗
- 排列型和跑马灯型主体透明度最低值都调整为真实 `0%`，并兼容迁移旧版滑杆最低档；跑马灯同时支持独立字体、展示数量、纵向位置与三档速度，未锁定时只能上下拖动，锁定后触摸穿透，系统关闭动画时自动回退为静态横排
- 排列型和跑马灯型的透明度滑杆改为松手后一次性生效，拖动过程中不再持续写入设置并刷新悬浮窗，降低跑马灯运行时的卡顿风险
- 减少跑马灯行情刷新开销：只更新变化的价格文本和颜色，轨道建立后冻结价格列宽，避免重复测量、图标重绑、窗口布局提交及动画重启；相同行情快照自动去重，主线程繁忙时只处理最新一帧
- 跑马灯滚动改为直接作用于轨道 `translationX` 的属性动画，移除业务层逐帧位移回调；当前悬浮窗口与应用页面仍共享同一进程主线程，高刷新率设备在首页重绘或页面切换期间仍可能出现短暂滚动顿挫
- 跑马灯行情单元使用 `16dp` 图标、按当前价格格式独立测量且最大 `58dp` 的左对齐价格列，以及 `4dp` 项间距；轮次边界固定为普通可见间距的两倍，`3dp` 低亮度圆点居中后距末项价格和下一轮首项图标各一个普通可见间距
- 旧悬浮窗配置继续映射到排列型，新跑马灯配置写入独立 DataStore 键；首次纵向位置可继承旧窗口坐标
- 悬浮币对新增独立全局顺序，并拆分为单独的“悬浮币对”页面，可跨交易所与链上币对拖动调整；拖动把手独占手势，避免与页面滚动冲突。首页置顶和分页内排序不再改变悬浮窗顺序，两种悬浮类型按同一顺序分别截取前 N 项
- 修复悬浮币对换位时节点身份被重绑定、相邻项坐标短暂重叠以及显示范围标记改变行高导致的闪烁和顺序回弹
- 修复开启或关闭悬浮币对时上下分区重复刷新和已选列表晚一帧同步造成的布局抖动
- Room 升级到 v9，`overlaySelected` 与可空的 `overlayOrder` 在同一事务中更新；v8→v9 会按升级前实际悬浮顺序初始化已选币对，未选币对保持空顺序

## v1.0.8 (2026-09-04)

- 首页观察列表拆分为可点击、可左右滑动的“交易所 / 链上”分页，默认显示交易所；两个分页分别保留滚动位置，空状态也按市场类型独立展示
- 移除首页“关注”标题，将市场切换栏与右侧添加按钮放在同一水平行；同步缩小币对、价格、涨跌幅、标签、图标与行内间距，降低单项高度
- 首页添加按钮和空状态入口会让搜索页默认进入当前市场模式；拖动排序与置顶只调整当前分类的可见顺序，删除、悬浮窗选择和全局下拉刷新保持原行为
- 设置页新增独立“关于”页面，自动读取当前构建版本，并提供项目说明、作者主页、源码仓库、Apache-2.0 许可、GitHub Issues 与行情风险说明
- 新增轻量级应用更新检查：每次主界面创建时请求 GitHub 最新已发布 Release，发现更高版本后提示打开 Release 页面；无 24 小时缓存，不接入第三方服务，也不自动下载或安装

## v1.0.7 (2026-09-04)

- 链上搜索取消本地链白名单与 80 条结果上限，按 DexScreener 实际返回的 `chainId` 展示并持久化未知网络；Robinhood 等未预注册网络也可继续刷新报价
- 链与代币图标采用“DexScreener 代币图标 / 本地链映射 → 在线链图标候选 → 内置默认占位图”回退，在线图片请求失败不会再中断列表或悬浮窗渲染
- 链上报价新增“智能刷新 / 固定间隔”模式：按链和每 30 个地址拆分请求批次，在完整轮转周期内顺序分散发送，并保证相邻请求至少间隔 1 秒
- 智能刷新以 DexScreener 的 30 秒缓存窗口为基础自动规划轮转；固定模式支持 30、45、60、120 秒，手动刷新复用同一队列并跳过 30 秒内已成功刷新的批次
- 链上刷新设置页新增当前批次数、批次间隔、轮转周期和失败重试状态；单批失败采用独立退避，不阻塞其他批次继续刷新

## v1.0.6 (2026-09-01)

- 链上搜索和价格完全切换到无需 API Key 的 DexScreener，K 线切换到 GeckoTerminal；移除原链上接口、WSS、签名和凭证设置
- Room 升级到 v8，旧链上观察项保留原 ID 并迁移到通用 `ONCHAIN` 来源，首次刷新时自动持久化固定池地址与代币方向
- 吸附靠边新增“仅吸附靠边 / 彻底隐藏”互斥模式；彻底隐藏时只保留主题色半透明边条，点击后按原吸附跑马灯样式展开，再按用户设置的 `1–5 秒` 延迟平滑收回
- 悬浮窗配置统一改用 Preferences DataStore，旧 `overlay_settings` 单行配置在现有 v7→v8 迁移中一并导入；币对及悬浮窗选中状态继续由 Room 管理，不新增 v8→v9 迁移
- 增加基于 Room `MigrationTestHelper` 的真机迁移测试，使用导出的 v7 schema 实际验证 v7→v8 数据与 schema，以及旧悬浮窗配置经 SharedPreferencesMigration 导入 DataStore 的完整链路
- 链上价格使用独立轮询周期，默认 `45 秒`；轮询滑块保留 Material 3 原生轨道并显示低间隔限流风险渐变
- 新增按链批量报价、固定池复用、池失效重选、429 退避、GeckoTerminal K 线缓存与请求取消支持
- 搜索页拆分为独立的“交易所 / 链上”分页与查询状态；交易所并行搜索多个来源并在全部结束后一次性展示，链上搜索取消手动选链
- 链上搜索结果改为按“链 + 代币合约”去重，直接展示实际交易对、链 Logo、DEX、流动性与合约缩写
- 同一代币支持在结果内展开并切换高流动性备选池；已添加标的会立即持久化新池，未添加标的会在添加时保存选择，后续价格与 K 线共用该池
- 修复链上 `3D / 1W / 1M` K 线使用 GeckoTerminal 无效日线聚合参数的问题，改为请求合法的 `day + aggregate=1` 后在本地合并 OHLCV
- 修复 DexScreener 返回官方允许的显式 `null` 时可能导致整个响应解码失败的问题，覆盖空 `pairs`、`labels` 与 `priceChange`
- 修复快速连续切换链上池时旧请求可能覆盖最后选择的问题：同一标的的写入按代次串行收口，报价落库前再次校验请求发起时的池绑定
- 修复报价与 K 线任务通过 `runCatching` 吞掉协程取消的问题，快速切换标的或周期时旧任务不再进入成功或失败回调
- 搜索结果改为 `LazyColumn` 逐条惰性组合，不再把最多 80 条结果一次性放入同一个 item
- GeckoTerminal 长周期日线按单次 1000 根使用 `before_timestamp` 向前分页；链上固定 30 日周期在界面显示为 `30D`，与交易所自然月 `1M` 明确区分
- 交易所聚合搜索改为等待五路并发来源全部结束后统一合并、排序并一次性展示；单路失败会短重试一次，重试后仍失败会保留其他来源结果并明确提示，同一关键词重复提交不会重建请求
