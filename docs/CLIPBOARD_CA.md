# 悬浮快捷查询

更新时间：2026-10-11。

## 界面与入口

- 排列型与跑马灯沿用现有独立设置、拖动、贴边、收边恢复、币种排序及滚动实现，接入新版 Android 语义配色。排列型普通窗口使用 14dp 圆角、12dp 币种图标和 11sp 基础价格字号；跑马灯保持全宽单行，基础高度 28dp、图标 12dp、字号 11sp。字号设置与实际渲染使用同一基准，已保存的缩放比例继续生效。
- 新配置默认背景透明度为 90%，允许调至 100%；已保存的透明度、字号比例、位置和模式继续保留，不强制覆盖用户配置。
- 复制内容后，点击未锁定的行情浮窗查询；拖动不查询。贴边收起时，第一次点击展开行情，再点击查询。锁定穿透行为继续沿用。
- 点击后临时打开可获得焦点的窗口，再读取剪贴板文本；没有后台剪贴板监听，不读取文件、图片或内容 URI。
- 查询卡片跟随 App 浅深色，宽度最高 250dp，窄屏使用可用宽度；14dp 圆角、6dp 内边距、3dp 内容间距。卡片按自然内容展开，超过当前屏幕安全高度时卡片内容滚动。
- 快捷查询网站按用户顺序两列排列，每行固定 28dp、行间隔 3dp；区域固定 121dp，默认露出四整行，多余网站在区域内部滚动。项目资料图标块保持独立，不跟随快捷网站网格滚动。钱包的 GMGN/浏览器入口沿用自然高度，无多余固定空白。
- 标题、网络与短地址集中在顶部信息栏，复制、设置和关闭使用 28dp 控件；设置不再占用整行底栏。正文使用 10–12sp 字号，钱包估值 18sp，普通操作采用 28dp 基础高度，网站图标 14dp，网络菜单最高 280dp。价格与走势图共用一个至少 56dp 高的区域：折线图位于右侧三分之二，左侧报价数字缩到 15sp，价格/市值标签为 9sp。报价、涨跌幅和人数均不添加文字背景；长报价可以在左侧换行，区域随内容增高。
- 代币/钱包分段切换缩到一行宽度的一半、20dp 基础高度；代币结果右侧只放置 20dp 开关及无底色 `＋`，取消“悬浮窗”可见文字，开关仍保留完整辅助功能说明。已加入时显示 `✓`，仍可移出自选；钱包模式不显示这些代币操作。底部只保留 24dp 基础高度的 GPT/Grok 浅底色按钮，14dp 品牌 Logo 位于文字左侧，颜色跟随主题，不再单独占一行放悬浮开关。大字体文本可扩展自然高度，快捷网站仍保持固定行高，长名称单行省略。
- 钱包估值与标题、展开与刷新分别并行显示；持仓行基础高度 32dp，窄屏、大字体或长估值自动换行，保留完整金额。FoMo 链名、短地址和复制放在同一行，解析钱包入口继续直接可见。
- 关闭、返回、外部点击、失去焦点及隐藏浮窗均关闭当前查询并取消网络任务。地址/网络切换与新读取隔离旧结果及旧错误；地址只在显式点击复制按钮时写入剪贴板。

## 代币 CA

- 多个地址先选地址，多链结果先选链。Solana 必须解码为 32 字节地址，EVM 使用完整地址边界；不能从更长密钥中截取片段。
- 继续复用 DexScreener 的精确 CA/交易池选择规则。市值和项目链接只使用目标代币为基础侧的数据，缺失市值显示 `--`。
- 主数值可切换价格/市值，该选择为全局偏好；涨跌幅直接紧邻价格/市值标签，其后为切换图标。百分比前不再显示 `24H`，统计周期移到右侧人物人数之后；人数的辅助功能保留完整描述。右侧短走势图始终表示价格，不再显示走势标题、数据来源或跨度说明；不改变价格点的真实时间坐标，右侧 `24H` 表示涨跌幅统计周期，不把图的范围标为完整 24H。走势加载和不可用状态仅使用小指示图标，走势与人数独立加载，失败不影响基本报价。
- 已启用的快捷查询网站遵循保存顺序；没有当前网络规则的入口不可点击。DexScreener 返回的项目资料链接独立显示在无底色的“项目链接”行，不和 DexScreener、GMGN、OKX 等查询入口混排。标题直接显示，去掉整块内边距，图标布局高度 20dp。
- 项目官网使用地球图标，Docs 使用文档页图标，Twitter 显示 `X`，Discord 使用其品牌图标。只展示当前行情返回的实际链接；其他类型保留通用链接图标，多个链接可以换行，不隐藏或替换地址。长按图标可查看类型及主机名，辅助功能也保留描述。
- 项目资料来自当前基础代币的 DexScreener `info.websites` 与 `info.socials`，报价侧不能继承基础侧资料。[DexScreener 的资料说明](https://docs.dexscreener.com/token-listing)包含外部代币列表及项目资料更新来源；App 未独立核验链接所有权，不将这一块标为“已验证官方”。
- 固定 GPT/Grok 操作把当前代币名称、网络、完整 CA、价格和可用市值带入提问。Android GPT 使用 ChatGPT 网页草稿，Grok 使用网页查询；没有复刻 Mac 专属的本地 Codex 新聊天入口。通用问题可在快捷查询设置中保存或恢复默认，文字正确编码，不把未知值写成示例数据。
- AI Logo 复用 Mac `ClipboardLogoGPT` / `ClipboardLogoGrok`：GPT 为 OpenAI 桌面应用的符号，Grok 来源为 Lobe Icons 1.95.1（MIT）。Android 使用主题着色的矢量资源，保留原始路径精度，不在运行时下载 Logo。
- 加入/移出自选沿用原逻辑。“加入悬浮窗”对已有自选即时生效，未加入自选时决定之后添加是否同时显示。

## 悬浮窗内的钱包解析

- 地址卡片提供“代币 / 钱包”切换。未匹配到代币或代币查询失败并不能证明地址是钱包，用户可手动切换钱包查询。
- 复用现有 OKX 只读资产服务及用户的加密 API 配置。Solana 直接使用对应网络，EVM 在没有明确网络上下文时先选择网络。
- 当前实现取得地址资产快照后只展示所选网络的非风险资产；估值使用该网络可定价资产的 BigDecimal 汇总，不挪用全链总额。无价格资产保留，估值标为“可估值持仓”。
- 卡片先展示前三项，用户可在同一窗口展开全部持仓，手动刷新或打开当前网络的 GMGN/区块浏览器链接。
- 查询服务缺凭证时展示设置入口，不展示估值。刷新失败保留当前地址的上次成功结果及其时间；新输入清除旧地址结果。
- 钱包查询和 FoMo 地址只保存在当前窗口会话内存，不保存观察地址、备注或持仓缓存，不改变原观察地址页的最近地址及隐藏偏好。
- 本轮只实现悬浮解析，没有新监控列表、监控详情页、添加监控按钮、地址持仓常驻浮窗、后台轮询或交易提醒。

## FoMo 用户地址反查

- 优先识别文字里的 `fomo.family/profile/<handle>`，包括形似 CA 的用户名。只接受真实主机、合法路径及用户名；多个主页先选用户。
- 与当前 Mac 解析流程一致：公开第三方索引 `985monitor.xyz` 提供用户及近期交易关联，忽略其 `wallets` 缓存字段。每类最多核验两笔不同交易。
- Solana 核对成功状态、区块时间、交易签名、代币 owner 净变化及 owner 签名者身份，使用原子整数计算，不能仅凭手续费支付者认定地址。
- EVM 核对成功收据、交易哈希、时间和 ERC20 净流向，排除中间路由，并匹配当前 Mac 使用的 FoMo EIP-7702 委托。只读 RPC 映射为 Ethereum、BSC、Base、Robinhood、Monad；这不代表所有网络均经本次真实查询验证。
- 两笔交易得到不同地址时不静默选择。未找到用户、证据不足/冲突、网络失败及超时分别提示；仅一类成功时保留结果，另一类标为未确认。没有地址结果不能解释为用户没有钱包。
- 卡片显示用户名、可用真实头像、Solana/EVM 地址、完整复制和主页入口。通过“查看解析钱包”在同一窗口查询持仓；EVM 先选网络，可返回原 FoMo 结果。
- 头像只允许 HTTPS 的索引主机和 FoMo profile-pics S3 主机，独立 6 秒超时、1 MiB 和解码尺寸限制；失败不显示虚构头像或阻塞地址。网络不带登录凭据/钱包密钥，不写网络日志、Cookie 或磁盘缓存，不跟随头像重定向。
- 用户交易的第三方归属仍是关联证据，链上匹配不等于本人完成钱包所有权认证。总解析超时 20 秒，错误不自动重试；关闭或新输入后旧结果不得重新进入窗口。

## 快捷网站配置

- 内置入口共 12 个：DexScreener、GMGN、OKX、Binance、X、Explorer、Fomo、Pump.fun、Ave.ai、Axiom、Debot、Birdeye。Pump.fun 与 Axiom 仅提供 Solana 路由；Ave.ai 使用 `https://ave.ai/token/{ca}-{chain}`，映射 Arc=`arc`、BNB Chain=`bsc`、Ethereum=`eth`、Robinhood=`robinhood`、Solana=`sol`；Debot 使用 `https://debot.ai/token/{chain}/{ca}`，Birdeye 使用 `https://birdeye.so/{chain}/token/{ca}`，两者映射 BNB Chain=`bsc`、Robinhood=`robinhood`、Solana=`solana`。新增规则依据用户提供的详情链接和截图，未独立验证所有网络上的网站详情页可用性。
- 升级首次加载时只追加缺失的五个新增内置网站，已手动添加的相同路由不重复加入；保留已有网站顺序、名称、开关、自定义规则及旧入口删除状态；保存迁移版本后，用户再次删除的新入口不会在重启后复活。恢复默认仍是显式操作。
- Ave.ai 的 `CA-网络` 后缀参与本地识别；Pump.fun/Axiom 的无网络路径按精确内置模板识别为 Solana，不用于其他网络。新增图标使用各站点 favicon，加载失败沿用通用图标。
- 新增/编辑通过真实详情页链接识别网站名称、图标来源、地址位置及网络规则。唯一 CA 自动处理，多个 CA 必须选择，无地址或无效链接不能保存。
- 已知且格式精确匹配的内置路由复用其现有网络规则；陌生网站只使用粘贴链接已确认的网络，不推断其他链。
- CA-only 链接不显示网络表。使用网络名称或逐链完整链接时规则默认展开，可编辑、增加和删除；名称和链接预览可见，不要求用户编辑整个原始模板或多行映射字符串。
- 同格式再次识别保留用户名称、手动规则和删除标记，不恢复已删网络；网络规则全删后入口保持不可用，可再次手动添加。旧配置兼容新增字段，保留网站 ID、顺序、启停和原自定义网址。
- 图标按网址来源加载，失败使用通用图标；保存不依赖成功下载图标。网站可行内编辑、通过更多菜单删除或用手柄拖动排序；恢复默认是显式操作，保留自建网站。
