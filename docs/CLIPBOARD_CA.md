# CA 悬浮信息卡

- 复制 CA 后，点击未锁定的排列型或跑马灯悬浮窗查询；拖动不查询。贴边收起时，第一次点击仍展开原行情，再点才查询。
- 点击后临时打开可获得焦点的面板，再读取当前剪贴板文本。没有后台监听，也不读取剪贴板里的文件或图片。
- 多个地址先选地址，多链结果先选链；每条链复用现有交易池选择规则，精确匹配 CA。
- 信息卡优先在原悬浮窗下方展开，空间不足时向上；内容超高可滚动。关闭按钮、返回、点外部、失去焦点或隐藏悬浮窗都会收起并取消查询。
- 展示名称、链、短地址、价格、市值、持仓人数及可用涨跌幅。市值、项目链接只采用目标币为池子 base 一侧的数据；缺失市值显示 `--`。持仓人数按链和 CA 从 GeckoTerminal 独立加载，失败时不占位，也不影响基本行情。
- 近 24 小时走势来自 GeckoTerminal，与基础查询独立加载；失败不影响基本行情。DexScreener 按选中交易池打开；其他快捷网站按目标链和 CA 打开，不支持的链置灰。
- 可以加入或移出自选。信息卡内的“加入悬浮窗”开关对已有自选币种立即生效；尚未加入自选时，该开关决定点击加号后是否同时加入悬浮窗。
- 设置支持功能总开关、快捷网站启用/删除、拖动排序、恢复默认、自定义网址和链映射。编辑、删除、开关和拖动手柄位于同一行；恢复默认会保留自建网站。
- 查询仅按需发生，重复查询最多复用 60 秒内的结果，没有定时轮询。未发现 CA、无有效交易池、请求失败分别提示；基本查询和走势为 15 秒超时，持仓人数为 8 秒超时。
- 设置页使用与其他二级设置页一致的居中 Toolbar 和覆盖式进出场动画。

验证边界：代码测试、静态检查和 APK 构建不能证明设备上的剪贴板焦点兼容性或实际动画效果，需后续人工确认。
